# Designs

This folder is the source of truth for design files in this repository.

Use a clear, simple structure such as:

- `designs/examples/` for reference models and studies
- `designs/functional/` for practical printable parts
- `designs/fixtures/` for tool jigs and calibration pieces

Every OpenSCAD model should be readable, parametric, and meant for remixing. Add comments when a design depends on a particular printer or fit constraint.
